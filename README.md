# Devstagram

A social media platform for developers to share their coding achievements, projects, and tech insights.

## Features

### 📑 Snatch Feature

The "Snatch" feature allows users to save posts for later viewing, similar to bookmarking. This is perfect for when you see an interesting post but don't have time to read it fully.

**How to use:**
1. Click the 📑 bookmark icon on any post to snatch (save) it
2. The icon changes to 🔖 when a post is snatched
3. Click "My Snatched Posts" in the header to view all your saved posts
4. Click the 🔖 icon again to unsnatch (remove) a post from your saved collection

**Features:**
- Persistent storage using browser localStorage
- Visual feedback with animations when snatching/unsnatching posts
- Counter showing the number of snatched posts
- Dedicated view for browsing all snatched posts
- Empty state message when no posts are snatched

## Getting Started

Simply open `index.html` in your web browser to start using Devstagram.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for data persistence
